Qt support some **QIODevice** sub classes:
- Random access data
    - **QFile**: Accesses files in the local file system and in embedded resources
        - QFileInfo classes, which handle directories and provide information about the
        files inside them
        - QIODevice::seek() function for repositioning the file pointer.
    - **QTemporaryFile**: Creates and accesses temporary files in the local file system
    - **QBuffer**: Reads data from or writes data to a QByteArray
    - **QDataStream**
    - **QTextStream**
- sequential transmission
    - **QProcess**: Runs external programs and handles inter-process communication
        -  launch external programs and to communicate
        with them through their standard input, standard output, and standard error
        channels (cin, cout, and cerr).
    - **QTcpSocket**: Transfers a stream of data over the network using TCP
    - **QUdpSocket**: Sends or receives UDP datagrams over the network

## Read and write binary data

Qt provides `QDataStream` to serialize C++/Qt objects into binary files and restore them later.

Used for:
- Saving structured data (images, maps, custom types)
- Fast binary storage (not human-readable)

Refer:
- Example [_19_IO](../_19_IO/main.cpp)

---

## 1. Core Classes

### QFile
Handles file access:
```cpp
file.open(QIODevice::WriteOnly | QIODevice::ReadOnly)
```

Common modes:
- WriteOnly -> write data
- ReadOnly -> read data

---

### QDataStream
Handles serialization (convert objects ⇄ binary)

Key functions:
```cpp
QDataStream out(&file);
QDataStream in(&file);
```

Important:
```cpp
setVersion(QDataStream::Qt_4_1);
```

Why version matters:
- Ensures compatibility between Qt versions
- Same format for read/write

---

## 2. Write Process

### Steps
1. Open file in WriteOnly mode
2. Create QDataStream
3. Set version
4. Write data in strict order

### Example flow:
```cpp
QFile file("data.dat");
file.open(QIODevice::WriteOnly);

QDataStream out(&file);
out.setVersion(QDataStream::Qt_4_1);

out << magic << image << map;
```

### Key idea
Binary stream = sequential packing of bytes

Order matters:
```
magic -> image -> map
```

---

## 3. Read Process

### Steps
1. Open file in ReadOnly mode
2. Create QDataStream
3. Set SAME version
4. Read in SAME order

### Example flow:
```cpp
QFile file("data.dat");
file.open(QIODevice::ReadOnly);

QDataStream in(&file);
in.setVersion(QDataStream::Qt_4_1);

in >> magic >> image >> map;
```
